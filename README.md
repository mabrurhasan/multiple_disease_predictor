

Multiple Disease Prediction System 🩺🤖

A Machine Learning-based Multiple Disease Prediction System built using Python and Streamlit. The application provides a simple web interface where users can enter relevant medical parameters and receive predictions for Diabetes, Heart Disease, and Parkinson's Disease.

🚀 Key Features

- 🔹 Diabetes Prediction using a trained ML model
- 🔹 Heart Disease Prediction using patient health parameters
- 🔹 Parkinson's Disease Prediction using relevant clinical features
- 🔹 Interactive Streamlit web interface
- 🔹 Separate prediction pages with easy navigation
- 🔹 Pre-trained models saved using Pickle (".sav")
- 🔹 Real-time prediction based on user-provided inputs
- 🔹 Deployable as a public web application through Streamlit Community Cloud

🛠️ Technologies Used

- Python
- Machine Learning
- Scikit-learn
- Pandas & NumPy
- Streamlit
- Pickle
- GitHub

🔄 How It Works

1. Medical datasets are used to train individual machine learning models.
2. The trained models are evaluated and saved as ".sav" files.
3. Streamlit provides an interactive interface for entering patient parameters.
4. The application loads the appropriate trained model.
5. The model processes the input and displays the prediction.

🎯 Objective

The goal of this project is to demonstrate how machine learning models can be integrated into a user-friendly web application for educational disease-risk prediction.

«Note: This application is intended for educational and demonstration purposes and should not be used as a substitute for professional medical diagnosis.»
